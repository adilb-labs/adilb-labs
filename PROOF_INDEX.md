# Proof Index

This page is a public, bounded index of evidence that supports the services offered on this profile.

It is intentionally **not** a dump of private source code, internal governance, customer data, or proprietary implementation details.

## Proof rule

`DESIGN != STATIC_CODE != EXECUTION != VERIFIED_RESULT != PRODUCT_READY`

Every proof item below is stated only at its supported level.

## P1 — ARC-AGI-3 2026 / Interactive Agent Evaluation

- V8 official public leaderboard score: **30.96**
- submission reference: **57455070**
- frozen source identity preserved by SHA-256
- exact-source rerun later produced **26.27**, demonstrating that exact artifact identity does not guarantee identical stochastic/platform outcome
- work included failure diagnosis, generalization checks, trajectory analysis, action efficiency, negative-result preservation, and probe-vs-commit analysis

## P2 — Industrial Numeric Authority / Boundary Proof

**Evidence class:** Executed and tested numeric core within its bounded scope

The industrial optimization program established explicit classification for:
- no fit
- exact fit / zero leftover
- positive unusable leftover
- positive usable leftover

The numeric baseline was treated as the sole numeric authority, with integer-only arithmetic and explicit boundary cases.

**Supports:** Calculation logic validation, estimation / optimization QA, boundary-case design.

**Does not prove:** full commercial readiness of the complete AluCut product.

## Why this proof structure matters

A client should be able to answer:

- What was actually executed?
- What was only designed?
- What is public proof?
- What is a bounded internal result?
- What is still unknown?
- Which service claim is supported by which evidence?

That is the standard applied to paid engagements as well.
